## Task
Electricity price reconstruction for the AET Neural Wave 2026 challenge: from hourly to quarter-hourly prices.

Reconstructs the four 15-minute prices of every hour from the 24 hourly day-ahead prices of a day,
for the four zones, so that each hour's four prices average exactly to its hourly price.

Model: **XGBCrossZone with one fixed shrink factor** (see [METHODOLOGY.md](METHODOLOGY.md)).
Validation MAE on a rolling forward-in-time split (May–Aug 2026): **3.874 EUR/MWh**
(flat baseline 8.215).

### Install

Python 3.13 or 3.14.

```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Predict (inference, what the jury runs)

The trained model is included in `artifacts/`; no training and no network access are needed.

```bash
python predict.py --test test_hourly.csv --history history_15min.csv --output predictions.csv
```

- `--test`: `delivery_date, market_id, hour_index, hourly_price_eur_mwh` (one or more dates).
- `--history`: `delivery_date, market_id, hour_index, quarter_index, price_eur_mwh`. Optional; for each
  date only rows from strictly earlier dates are used, whatever the file contains.
- Output `predictions.csv`: `delivery_date, market_id, hour_index, quarter_index, predicted_price_eur_mwh`.

Before writing, `predict.py` checks the output against the rules (four finite prices per hour, no
duplicates, every input hour covered, hourly mean within 1e-4 EUR/MWh). If a check fails it writes
nothing and exits with code 1. A day takes about one second.

### Train (regenerates `artifacts/`)

```bash
python train.py --data data/train_prices_15min.csv
```

Trains on the whole official training set (1 Oct 2025 – 30 Sep 2026, 363 days) in about 4 minutes
on a laptop CPU, with fixed seeds. Writes `artifacts/model.joblib` and `artifacts/model_info.json`
(training period and the fixed shrink factor). The training file is not included in the repository;
place the official `train_prices_15min.csv` in `data/`.

### Tests

```bash
pytest -q
```

- `tests/test_no_lookahead.py`: scrambles one day's quarter prices (hourly prices unchanged) and
  checks that no feature of that day or any earlier day changes.
- `tests/test_predict.py`: runs `predict.py` with the trained model on a normal day, two dates,
  no history and a missing zone, and checks every output against the rules.

Both need `data/train_prices_15min.csv`.
