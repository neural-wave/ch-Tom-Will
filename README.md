## Task: Electricity price forecasting project for the AET Neural Wave 2026 challenge.

The project predicts quarter-hour electricity prices from hourly prices. It includes:

- A flat hourly baseline
- An interpolation baseline
- Monthly and rolling-origin evaluation tools for splitting the data
- MAE scoring and compliance checks
